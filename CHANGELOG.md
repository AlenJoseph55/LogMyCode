# Change Log

All notable changes to the "logmycode" monorepo will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [2.1.0] - 2026-03-11

- **Feat**: Implemented persistent settings and enhanced logging in the VS Code extension.
- **Feat**: Added Standup Mode and Manual Work Log features.
- **Refactor**: Improved UI and history fetching logic.
- **CI/CD**: Configured GitHub Actions for automatic extension packaging and releases.

## [2.0.0] - 2026-02-17

- **Feat**: Initialized monorepo structure with `packages/backend` and `packages/vscode-extension`.
- **Docs**: Added comprehensive `README.md` for the project.
- **Feat**: Configured workspace-level scripts and tooling (Turbo, ESLint, Prettier).
